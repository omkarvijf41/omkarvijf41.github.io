# Omkar Atluri — Professional Portfolio

Custom-built responsive portfolio for GitHub Pages.

## Expected site URL
https://omkarvijf41.github.io

## Enable GitHub Pages
1. Open **Settings → Pages** in this repository.
2. Under **Build and deployment**, select **Deploy from a branch**.
3. Choose branch **main** and folder **/(root)**, then save.
4. Wait for the Pages deployment to complete. The site URL will appear on the Pages settings screen.

## Sections
- Professional introduction and engineering positioning
- About and engineering approach
- Selected portfolio projects, including the AI Enterprise Modernization Assistant
- Technical expertise
- Contact links to LinkedIn and GitHub

## Local preview
Open `index.html` in a browser, or run:

```bash
python3 -m http.server 8080
```

Then visit http://localhost:8080.
